Sistema de Controle de Aluguel de Quadra

## Tabelas Identificadas

Cliente
- id
- nome
- telefone

Horario
- id
- horaInicio
- horaFim
- valor

Aluguel
- id
- cliente
- data
- horarios
- valorTotal
- pago



## Regras de Negócio

- Não permitir nome vazio
- Não permitir valor negativo
- Não permitir horário ocupado
- Calcular valor total automaticamente
- Consultar aluguéis por data
